# Open Pac-Man

## Commands

- Requires the .NET 10 SDK (`net10.0`); build with `dotnet build open-pacman.csproj`.
- Run locally with `dotnet run --project open-pacman.csproj`; the `http` launch profile serves `http://localhost:5255`.
- There is no test project, linter, formatter, solution file, or CI configuration. Use the build as the available automated verification.

## Architecture

- This is a single Blazor WebAssembly application. `Program.cs` mounts `App` into `wwwroot/index.html`; routing resolves `/` to `Pages/Home.razor`.
- Keep game rules and state in `Game/PacmanGame.cs`. `Pages/Home.razor` owns the canvas lifecycle and JS interop; `wwwroot/js/pacman.js` owns keyboard input and Canvas 2D rendering.
- `pacman.js` imports as an ES module from `Home.razor` and invokes `[JSInvokable]` methods named `Tick` and `SetDirection`. Preserve those names and the `GameFrame`/`ActorFrame` JSON shape when changing either side.

## Game Invariants

- The maze uses 28 columns by 31 rows and the renderer uses 20px tiles; keep the canvas dimensions (`560x620`), CSS aspect ratio (`28 / 31`), and maze/grid dimensions synchronized.
- Grid values are a cross-language rendering contract: `0` empty, `1` wall, `2` dot, `3` ghost-house door, and `4` Power Pellet.
- Do not edit `bin/` or `obj/`; they are generated by the .NET build.
