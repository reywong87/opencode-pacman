# Open Pac-Man

## PacMan like!

Vamos a crear un juego de PacMan como el original, pero con una interfaz gráfica más moderna y sencilla.

## Tecnologías

- .NET 10
- Blazor WebAssembly
- C#
- JavaScript
- HTML y CSS

# Spec Driven Development

El proyecto sirve para aprender este enfoque de desarrollo.
